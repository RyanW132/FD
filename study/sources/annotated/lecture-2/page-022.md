## Index mirror ratio

**Source region:** upper full-hedge formula and symbol definitions. **Classification:** substantive.

If a portfolio moves one-for-one with the index, the number of futures contracts needed for a full hedge is

$$N^*=\frac{V_A}{V_F},$$

where $V_A$ is the portfolio value and $V_F$ the **notional value of one futures contract**. Both values use the same currency.

## Index mirror example

**Source region:** lower example box. **Classification:** substantive.

A **$5 million** portfolio mirrors the S&P 500. An E-mini contract has a notional value of **$250,000**:

$$N^*=\frac{5{,}000{,}000}{250{,}000}=20.$$

To protect the **long portfolio** against a market fall, **short 20 contracts**.
